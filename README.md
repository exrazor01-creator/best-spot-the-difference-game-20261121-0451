**Twin Scenes** — a spot-the-difference game with three original hand-drawn scenes: a sunny harbor, a moonlit garden and a cozy cabin. Two pictures look the same; 21 differences hide across the three scenes. Click a difference on either picture to circle it, beat the clock, and use hints sparingly — a wrong click costs 5 seconds and a hint costs 50 points. All art is drawn in code with Canvas 2D, all sounds are synthesised with WebAudio, and the game runs fully offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no dependencies, no network.
